# Contributing

This repository is a **read-only mirror** of generated Go SDK code. Its
source of truth is
[isa-platform](https://github.com/Software-Automation-Holdings-LLC/isa-platform)
(`packages/*/go`), and its contents are force-published here by the
`sdk-publish` workflow on every release.

## Issues

Bug reports and questions are welcome — please open an issue describing the
problem (affected package/version, expected vs. actual behavior,
reproduction steps).

## Pull Requests

Because this repo's content is generated and overwritten on each publish
cycle, **pull requests opened directly against this mirror cannot be
merged** — any change here would be lost on the next sync. If you've found a
bug in the generated SDK, please open an issue here (or, if you know the
fix, a pull request against
[isa-platform](https://github.com/Software-Automation-Holdings-LLC/isa-platform))
instead.

See [SECURITY.md](SECURITY.md) for how to report a security vulnerability.
